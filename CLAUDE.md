# 11Ship — Claude implementation contract

Read [AGENTS.md](AGENTS.md) and [the mandatory delivery workflow](docs/process/11ship-delivery-workflow.md).

Implement only the approved task and UI. Return missing/conflicting business or UI design to ChatGPT/Owner. Provide exact-SHA tests/CI and a runnable local build before Owner local testing. Fix Owner feedback, supply fresh evidence and return for ChatGPT review. Prepare phone test builds after local acceptance. Owner decides final acceptance, merge and module closure. Use [the module checklist](docs/templates/module-delivery-checklist.md) for every task and each relevant app.
