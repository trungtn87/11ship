Chỉ backend `POST /v1/client-auth/register`. Không UI, không login/me/context/logout mới, không reset mật khẩu, không onboarding quán/xế, không native binding, không SMS nhà mạng. Không sửa schema (không DDL). Không sửa `docs/PROGRESS.md`, `plan.yml`, launcher.

## Ánh xạ
| Yêu cầu | Nơi thực hiện |
|---|---|
| Endpoint, 6 khóa body, 201 + `{data}` + `Cache-Control: no-store` | `client-auth/client-auth.controller.ts`, `client-auth-validation.ts`, `http/client-auth-transport.middleware.ts` (đặt trước body parser trong `app.setup.ts`) |
| Một transaction: claim idempotency → khóa/recheck proof (đồng hồ DB) → user PHONE_VERIFIED → consume proof → CUSTOMER/profile v1/consent → session CUSTOMER → audit → outbox → kết quả mã hóa | `client-auth/client-registration-service.ts` + `CustomerProvisioningParticipant` (M01.02), `SessionRepository.create(activeRole)` |
| Namespace tách khỏi legacy | scope `client_verification_proof`, operation `client.auth.register.v1`, audit/event riêng |
| Replay = token + expires_at gốc + identity HIỆN TẠI; authorize trước decrypt | `#authorizeReplay`, `ClientIdentityReader` (khóa proof → user → session; mọi từ chối → `AUTH_RESULT_NOT_REPLAYABLE` 409) |
| Consent theo cấu hình server, fail closed | `config/client-auth-config.ts` (`CLIENT_AUTH_TERMS_VERSION/PRIVACY_VERSION`), `client-auth-policy.ts` |
| WEB chỉ dev/test + loopback; ANDROID 503 trước mutation | `isLocalWebMode`, `assertDeviceAllowed` |
| Mã lỗi mới | `CONSENT_VERSION_UNSUPPORTED` 409, `AUTH_RESULT_NOT_REPLAYABLE` 409, `DEVICE_PROOF_REQUIRED` 403 (`common/app-errors.ts`) |
