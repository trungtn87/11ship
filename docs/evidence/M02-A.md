## Lock order (proved by `shop-management-boundary.spec.ts` + `shop-management-service.spec.ts` + A10/A11/A17)
idempotency advisory/record → user `FOR UPDATE` → session `FOR UPDATE` → OWNER membership → shop → service area `FOR SHARE` (profile only) → writes → audit → outbox → idempotency record. The GET takes user then session `FOR SHARE`, then reads once. Replay runs the same session authorization and the ownership check before decrypt.
