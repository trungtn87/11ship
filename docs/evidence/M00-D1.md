## What changed

- `render.yaml`: one Free Node web service, pinned Node 24.21.0 / npm 11.9.0, `npm ci --include=dev`, `npm start`,
  `HOST=0.0.0.0`, `APP_ENV=staging`, `NODE_ENV=production`, readiness health check, `autoDeployTrigger: "off"`,
  secrets `sync: false`, no migration var, no `PORT`.
- Strict pool TLS (`database/tls-config.ts`, `create-pool.ts`, `app-config.ts`): CA from `DB_SSL_CA` xor
  `DB_SSL_CA_FILE`; `rejectUnauthorized: true`; fail-closed in staging/production; URL query string refused when TLS
  is active (pg lets URL parameters override options); `NODE_TLS_REJECT_UNAUTHORIZED=0` refused. Local/CI unchanged.
- Remote migration path (`scripts/db-migrate-remote.js`, `npm run db:migrate:remote`): separate migrator
  credential, role must differ from runtime role, strict TLS (same resolver), target confirmation, session-pooler
  check-first (`--apply` required), history table `app.pgmigrations`, schema `app` never created by the tool, lock
  kept. `npm run db:migrate` refuses staging/production. No migration on build or boot.
- Runbook: `ops/runbooks/render-supabase-staging.md`.
- Dashboard: `docs/progress/plan.yml` group M00-D with leaves D1..D5.
