# Brand assets

The official 11Ship logo (SVG/PNG) is **not in the repository yet** (brand guideline section 12 lists it as open).
The logo must not be re-drawn, re-typeset or generated, so the client shows a clearly marked temporary text wordmark
(`<p class="wordmark" data-temp-wordmark="true">`, built in `src/app.js` `wordmark()`).

When the approved asset is added here, replace that one function with an `<img>`/inline SVG of the asset, keep its
aspect ratio and clear space (1X), and remove the `data-temp-wordmark` marker.
